A sleek white power strip whose own cable loops back and plugs into its own
socket — model **SP-∞**, green LED on, permanently self-powered. Its one
accessory is the proof: a small paper electricity bill leaning beside it,
reading **AMOUNT DUE $0.00** and **Usage: 0 kWh**.

## The gadget

- 4-outlet power strip, studio product-shot styling, clean light background
- Its own cable exits the right end, loops down and back, and plugs into
  socket 1 — the strip powers itself
- Green "ON" LED glowing, brand text "SELF-POWERED" on the body

## Run it

```sh
python3 main.py
```

Writes one image to `$MAKEFUN_OUTPUT_DIR/entry.png` (or `./out/entry.png`):
1024×768 PNG, drawn entirely with Python stdlib + Pillow, no network.
