a catalogue photograph of an impossible gadget.

## The gadget

**The SELF-POWERED power strip (model SP-∞).** A sleek white power strip
whose own cable loops back and plugs into its own socket — it powers
itself, forever. The green LED is on. The one accessory is the proof: a
paper electricity bill leaning beside it that reads **AMOUNT DUE $0.00**
and **Usage: 0 kWh**.

## How it works

`main.py` (Python 3.13, stdlib + Pillow only, no network) draws the whole
studio product shot with PIL and writes one image to
`$MAKEFUN_OUTPUT_DIR/entry.png` (fallback `./out/entry.png`).

```sh
python3 main.py
```

Output: 1024×768 PNG, under 1 MB.
