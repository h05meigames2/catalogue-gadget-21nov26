Entry for the make.fun bounty **the-catalogue-photo-of-an-2-20261121-0341**:
a catalogue photograph of an impossible gadget.

## The gadget

A sleek white power strip that powers itself: its own cable loops back
and plugs into its own socket. It never needs the wall — proven by the
one accessory beside it, its electricity bill: **$0.00**.

## How it works

`main.py` (Python 3.13, stdlib + Pillow only, no network) draws the studio
product shot at 2× supersampling and downscales it to a 1024×768 PNG.

```bash
python3 main.py   # writes out/entry.png (or $MAKEFUN_OUTPUT_DIR/entry.png)
```
